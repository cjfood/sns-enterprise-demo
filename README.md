# SNS - Sales Network System (Enterprise Platform)
**Commercial IP Demo Version | Copyright © 2026 Hien SE**

Hệ thống điều hành kinh doanh phân phối đa kênh (Multi-Channel Commercial & Distribution Management System):
- **4 Kênh phân phối tích hợp:** GT (General Trade - RTM), MT (Modern Trade), B2B (Food Service & HoReCa), KR (Key Accounts / Wholesale).
- **Trực quan hóa dữ liệu theo thời gian thực:** Dashboard KPI, Ma trận phân rã ngành hàng & nhóm sản phẩm, Bản đồ tuyến bán hàng & Golden Store DMS, Theo dõi chứng từ & tiến độ trả thưởng CTKM.
- **Kiến trúc Serverless / Static Standalone:** Tối ưu hóa 100% tài nguyên client-side, mã hóa binary streaming cipher 256-bit, giải nén siêu tốc trong RAM, tương thích hoàn toàn với GitHub Pages / Vercel / Netlify.

## Hướng dẫn trải nghiệm nhanh (Live Demo)
1. **Truy cập:** Mở liên kết GitHub Pages của dự án trên trình duyệt máy tính hoặc điện thoại di động.
2. **Đăng nhập:**
   - **Tài khoản:** `admin` (hoặc bất kỳ tài khoản demo)
   - **Mật khẩu:** `123456` (hoặc tùy ý)
   - Bấm **Đăng nhập** để vào thẳng hệ thống với toàn quyền Quản Trị Viên (Admin) Toàn Quốc.
3. **Thao tác chức năng:**
   - Xem tổng quan doanh số Sell-in / Sell-out Tháng 11/2026 và lũy kế YTD.
   - Lọc phân tích theo Kênh, Miền, Vùng, Nhà phân phối (NPP), Nhân viên bán hàng (NVBH).
   - Truy cập **Bản đồ tuyến** và **Theo dõi CTKM** ngay trên thanh Menu bên trái.
   - Xuất dữ liệu bảng biểu ra **Excel chuẩn định dạng** hoặc **Báo cáo PDF**.
